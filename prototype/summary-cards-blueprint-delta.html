新增 / 保留 / 移除什么

对话新增

  • statement 级摘要
  • asOf / partial
  • gaps / warning
  • 深链 CTA

保留

  • Host payload
  • DataOps 完整详情
  • 来源和状态
  • gaps
  • 现有卡片入口

对话移除

  • 字段列表
  • 完整 SQL
  • 列画像
  • 长 findings
  • 完整 join 覆盖
