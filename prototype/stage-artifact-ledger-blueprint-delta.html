Revision 是唯一事实源

ArtifactRevision

revisionId · contentHash · parentRevisionId · status · sourceTurnId

不可变；Agent 修改只创建新 revision。

CurrentIteration

stage · artifactId · revisionId · gate

悬浮窗 / StageStatusCard / turnTail / Dock 共用。

审批绑定版本gate 记录 revisionId + contentHash；换版本即失效。
旧版本不删superseded 只表示被替代，历史仍可查看。
卡片只是视图不把 payload 当当前产物。
悬浮窗只读修改回流 composer，由 Agent 生成下一版。
