让数据代码仓在改之前就能被看见。

Repo Doctor 是 DataOps tab 里的仓库体检视图。它只回答：当前 workspace 能不能被识别、有哪些 package 和 task、哪些地方会阻断构建或部署。它不接管文件浏览、源码预览和血缘。

本轮边界只新增 DataOps tab · 旧资产 / 血缘 / 证据 tab 保持不动 · 不做对话大卡 · 不做 IDE

一个命令命名空间人用命令，不是 Agent tool
/dataops

打开 DataOps 面板，不自动执行规则。

/dataops repo index

只建立 RepoIndex，不做判断。

/dataops repo validate

只执行规则，不重复遍历全仓。

/dataops repo check

index 过期时 index，然后 validate。

RESPONSIVE

620px指标一列两块；inspector 纵向；finding 路径换行。
720px指标四列；package 行和 finding 行完整展示。
1024px+可把 DataOps 放到更宽的面板，但 P0 不做全屏工作台。
ACCEPTANCE

这一版必须成立的事

  1. internal-code-repo 被识别为 DataOps 仓库
  2. 概览显示 5 packages / 4 tasks / 13 jobs
  3. 未识别时只提示正确 workspace，不递归搜索
  4. 占位符缺失为 warning，不是 blocking
  5. 错误态展示 code / stage / workspace / 重试
  6. 旧资产 / 血缘 / 证据 tab 不受影响
  7. /dataops 不产生对话大卡
  8. 只读，不执行 build / deploy
