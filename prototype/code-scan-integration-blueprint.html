  • 结果存储与 scanId

DataOps 负责

通过 `dataops CLI` 触发扫描，拿到 `scanId` 后轮询结果；在 `检查` 里展示 findings、impacts 和状态。

没有 scanId 或结果时显示“未运行”，不显示通过。

ACCEPTANCE

Mock 版验收标准

  1. 只有一个 dataops_code_scan 入口
  2. 触发后拿到 scanId
  3. 运行中显示 queued / running
  4. 只按 scanId 查询结果
  5. findings / impacts 原样展示
  6. CLI / 服务失败显示错误
  7. 无结果不显示通过
  8. 文件级 scope 可用
