证据是引用，不是正文

  • revision 只存 ref + summary
  • status / asOf 是引用时快照
  • 外部证据更新后回看 asOf
  • 没有证据显示“未关联”，不判 pass
  • 新 revision 需要显式重新关联

和现有能力的关系

scan 仍按 scanId；deploy 仍按 deploymentId；runtime 仍按平台坐标 + runId。

本版只展示证据，不把 evidence 数量变成 gate。完整证据正文仍在 DataOps「证据」section。

STATE GALLERY

证据为空、通过、警告、过期引用要分开

unlinked
设计 · v2

未关联证据。显示提示，不判失败。

pass
设计 · v3

scan pass + deploy pass；gate 仍待 BA。

warning
设计 · v3

runtime warn；显示黄点，不替用户下结论。

stale ref
设计 · v1

引用保留 asOf；证据失效时不改历史 revision。

ACCEPTANCE

这一版必须成立的事

  1. revision 保存 0–20 条 refs
  2. 非法 ref 被 stage prepare 拒绝
  3. 交付物显示证据数量
  4. 浮层当前阶段显示 chips
  5. 点击 chip 显示 asOf/summary
  6. 新 revision 不自动继承 refs
  7. 旧 revision 无证据显示未关联
  8. scan/deploy/runtime 坐标不变
