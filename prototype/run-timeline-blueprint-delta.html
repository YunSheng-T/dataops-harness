CONTRACT

结构化事件，不是原始日志

Input

RunTimeline：runId / taskId / status / events / errorCodes / recentRuns / asOf

来源是 `dataops_shared_read_logs` 的结构化输出。

View

事件按 seq/time 展示；错误码可复制；最近运行切换 runId。

不展示原始日志全文，不重算根因。

只读不 rerun / kill / deploy。
不冒充正常无事件或 partial 时显示缺失，不显示成功。
单一来源复用 dataops_shared_read_logs，不新增日志工具。
保留证据错误事件链接 evidenceRef，不复制正文。
