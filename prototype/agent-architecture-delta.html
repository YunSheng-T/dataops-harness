06 · What Stays

这些不要动

增量页也要明确“不改什么”，避免把架构调整扩大成 UI/阶段重做。
6 阶段模型需求 → 设计 → 方案 → 开发 → CICD → 复盘；排障仍是旁路。
原生 DSH UI不新开工作台、不替换会话；继续用 header chip / turnTail / toolview / rightbar。
卡片视觉现有 16 张卡继续用；presenter 只是产出同 kind/payload 的桥。
Mock 验收故事12 步工具脚本保留为确定性回归；用户入口另走自然语言。
07 · Decisions

增量版的三个拍板点

和建议全量版一致；先定取舍，再落代码。

WorkItem 先文件还是先服务？

P1 文件协议，P2 服务化；先保证 Agent 可恢复、可 diff。

建议：P1 文件

单 Lead 还是 Agent Team？

先单 Lead；评审/血缘/排障需要上下文隔离时再加子代理。

建议：单 Lead

内容工具何时收？

P1 保留兼容；P2 presenter 迁移内容；写 ADR 后删旧工具。

建议：P2 再收
