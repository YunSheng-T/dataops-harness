CHANGE SET

新增 / 保留 / 不新增什么

新增

  • ArtifactRevision.evidenceRefs
  • EvidenceRef 校验
  • DataOps 证据数量
  • 浮层证据 chips
  • 证据摘要 / asOf

保留

  • revision 不可变
  • gate 绑定 revision
  • scan 按 scanId
  • deploy 按 deploymentId
  • runtime 按平台坐标 + runId

不新增

  • 日志正文复制
  • 自动继承旧证据
  • 按 package 查运行
  • 用户手动拖拽关联
  • evidence 数量门禁
CONTRACT

引用而不是嵌入

ArtifactRevision

evidenceRefs[] 与 contentHash 同级；新 revision 默认空，必须显式关联。

EvidenceRef

kind · ref · status · summary · asOf · source；最多 20 条。

证据正文不复制revision 只保存引用和摘要；完整内容在证据服务。
不自动关联最近一次 deploy 不会自动成为当前 revision 的证据。
未关联不是失败显示“未关联证据”，不判 pass/fail。
坐标规则不变runtime 不按 package，deploy 不按 package。
