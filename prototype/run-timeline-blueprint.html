先发生了什么，卡在哪。

Run Timeline 把 `dataops_shared_read_logs` 的结构化结果整理成一条可读时间线。它不解析原始日志、不下根因结论，也不触发 rerun。

入口DataOps → 证据 → 运行时间线；复用现有 logs tool；不新增对话卡，不新增日志工具。

边界

时间线是日志信号的投影，不解析原始日志；根因判断由 `pipeline-debug` / 用户完成。只读，不 rerun / kill / deploy。

ACCEPTANCE

这一版必须成立的事

  1. mock channel-report 显示 8 个事件
  2. 失败事件和 DB_TIMEOUT 可见
  3. 无 runId 显示空状态
  4. running / partial / stale 有明确状态
  5. 不提供 rerun / kill
  6. 不新增对话大卡
  7. 复用唯一的 logs tool
  8. 不展示原始日志全文
