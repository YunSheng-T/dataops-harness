## 必须单独标记的高风险偏差

以下任一项发生，不能作为普通命名偏差处理，必须暂停并说明：

- 需要修改 DSH 核心或 fork。
- UI bridge 无法与原生 observation policy 安全组合。
- 无法获得 opaque FsVersion 或原子 replaceIfVersion。
- Agent 与其他 actor 无法继续原生 policy。
- 无法保证 dirty 草稿不默认共享。
- 无法保证 Artifact 动作 Host 重新授权。
- 需要生产 mock fallback 才能运行。

## 允许但需要记录的适配

- 按真实 DSH 包约定调整目录和 import。
- 使用仓库已有编辑器内核替代 CodeMirror 6。
- 将 headless Parser Registry 拆为独立依赖包。
- 在不改变语义的情况下调整 Remote 方法命名和错误封装。
- 根据真实 Remote outcome 增加真实 stat 以取得新 FsVersion。
