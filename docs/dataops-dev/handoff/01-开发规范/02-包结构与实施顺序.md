## 所有权

| 层 | 可以拥有 | 不得拥有 |
|---|---|---|
| Host DevDocument | documentId、权限、baseVersion、savedDigest、幂等记录、presence 元数据、Provider/Action Registry | 浏览器撤销栈、光标、每次 keystroke 的权威镜像 |
| Client Document Model | draftText、draftDigest、documentRevision、selection、sync/conflict、hot-exit 元数据 | 权限判定、Artifact 发布事实、Agent observation |
| Host Analysis | 按 digest 生成的 projection、diagnostics、sourceMap，可缓存可重建 | 独立可编辑 DAG、无 digest 的诊断 |
| Slot Store | tab、分栏、折叠、entityRef 选择、视觉布局 | 文件正文、FsVersion、权限、Evidence、生产状态 |
| DSH Native | Chat、Agent tools、文件 Resource/changes、Diff、Approval | dataops-dev 草稿和结构化投影 |

## 实施顺序

### 核查与 P0

- 完成上游证据记录。
- 注册最小“开发”视图，证明 focus 和 completeViewRequest。
- 复用文件树并打开一个真实文件。
- 实现一致性 open 和最小 save。
- 用集成测试证明：UI 受限保存可走通；Agent 未观察写仍失败；其他 actor 无 IDE 特权；竞争返回 stale。
- 若必须改 DSH 核心才能继续，先停下来提交缺口，不直接 fork。

### P1

- 增加单文件单模型、Tabs、dirty/saving/save-unknown/conflict。
- 完成幂等、reconcile、保存期间继续输入、external change、hot-exit。
- 完成只读、大文件、非 UTF-8、missing 降级。

### P2

- 增加 presence lease 和 Agent dirty guard。
- 增加 EditProposal 及 digest 过期检查。
- 接入原生 Diff；实现显式单次草稿共享。

### P3

- 用保留源码的 CST 实现 task.yaml 投影和 SourceMap。
- 增加白名单 setScalar、draft/saved analyze 和 Provider Registry。
- 结构化失败必须回退文本，不能用静态演示 DAG。

### P4

- 增加 savedArtifactRef、动作状态矩阵、统一 invokeAction。
- 开放五类 Slots，增加 Error Boundary 和贡献者版本。
- 用一个真实但简单的测试贡献插件证明扩展不需要修改 IDE 核心；该贡献只用于测试装配，不进入生产 mock fallback。

## 提交纪律

本地 Agent 不应在阶段中间改写不相关模块，不应格式化整个仓库，不应覆盖用户已有改动。每个阶段结束输出变更文件、测试证据和偏差。commit/push/merge/deploy 需要用户另行批准。
