# DSH 上游核查清单

本地 Agent 必须先阅读当前工作区的真实代码和 DSH 官方 `.agents/skills`，再决定 import、注册和测试方式。本设计核对的基线是：

```text
deepseek-ai/deepseek-harness
ce7073d51254c26cd63b22a60835b8f948deb447
```

本地版本可以不同，但必须在 `上游证据记录.md` 中写明实际 commit、路径、导出的符号和偏差。不得为了让参考代码编译而猜路径或修改上游公共 API。

## 必查文件与要证明的事实

| 上游路径（基线） | 必须确认的事实 | 对实现的影响 |
|---|---|---|
| `packages/api/workspace-files/README.zh.md` | `workspaceFiles` 提供 stat/read/readBytes/list/changes，不提供修改；分页文本读取不是事务性全文快照 | IDE 不能只靠 workspaceFiles；必须补 DevDocument，changes 用于失效通知 |
| `packages/fs/fs/README.zh.md` | `ctx.fs` 的读取、写入、原子发布和版本防护语义 | DevDocument 复用同一 ctx.fs，不建第二文件系统 |
| `packages/fs/fs/src/types.ts` | `FsVersion` 是 branded opaque；`FsWriteIntent` 的真实形态；错误码 | Remote 只能用 opaque transport token，不能解析或制造版本 |
| `packages/fs/fs/src/index.ts` | `writeText/editText/patchText` 的真实参数、返回值、signal 和 sandboxPolicy | 保存适配层按真实签名实现，digest 不由返回值臆造 |
| `packages/fs/fs-observation-policy/README.zh.md` | Agent read-before-write、恢复 Session 重读、非 Agent 限制、slot 组合语义 | UI bridge 和 Agent next() 是 P0 必验项 |
| `packages/client/ui-conversation/src/client/contract/views.ts` | `ConversationViewRequest` 的真实结构 | 深链只能按真实 view/focus 合同实现 |
| `packages/client/ui-conversation/src/client/contract/slots.ts` | `conversation.view` 的 scope/kind，openView/completeViewRequest 的真实 owner props | 注册“开发”视图，不替换 Chat |
| `packages/client/ui-sidebar-files/README.zh.md` | 文件树 Factory、navigator 生命周期、文件 Resource 和预览行为 | IDE 文件树优先复用通用 Factory，不误用 navigator |
| `packages/client/ui-deliverables/README.zh.md` | 文件卡片、review Diff 和 actions 扩展点 | 增加“在开发中打开”，Diff 不当当前磁盘真相 |

## 还需查找的真实样例

本地 Agent 应在仓库中找到至少一个现有功能插件，记录：

- package.json 的 name、exports、构建和测试约定。
- Host half 如何注册服务、Remote、Resource 和策略。
- Client half 如何注册 view、Slot、model 和 React 组件。
- RemoteError、stream/cancellation、session principal 的真实写法。
- preset 如何声明插件依赖和组合顺序。
- 单元测试与带真实 Host 的集成测试如何启动。
- 前端依赖如何安装，CodeMirror 是否已存在或可插件私有引入。
