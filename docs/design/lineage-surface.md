# Lineage Surface

> 状态：第一版已实现；右栏内联 + 半屏弹窗可用。
> 关联：OPEN-011 · [Summary Cards](summary-cards.md)
> 目标：完整血缘仍可交互，但不再默认占满整个页面。

## 1. 问题

`LineageSurface` 直接嵌在右栏时：

- 画布和详情被压窄
- 用户需要放大才能看清节点
- 全屏 overlay 会失去会话上下文
- 关闭/返回路径不自然

## 2. 两层布局

### 右栏内联

```text
当前会话 · 调度视图              [半屏打开]
┌────────────────────────────────┐
│ 血缘 surface                   │
│ 设计 / 生产 / 调度三视图        │
└────────────────────────────────┘
```

保留在 DataOps `血缘` section，作为快速查看。

### 半屏弹窗

点击 `半屏打开` 后：

- 独立 dialog，不占满全屏
- 桌面：`min(1120px, 74vw) × min(760px, 84vh)`
- 头部带关闭
- Esc / 点击外部 / 关闭按钮都能关闭
- 内部仍使用同一个 `LineageSurface`
- 小于 900px 时退化为全屏，避免不可用

## 3. 不变量

- 不复制血缘图逻辑
- 不新增血缘数据源
- 不改变三视图（设计 / 生产 / 调度）
- 不改变节点详情、聚焦、缩放
- 不把弹窗做成新的独立页面

## 4. 验收

1. 右栏内联不溢出
2. 半屏按钮可打开
3. 关闭按钮 / Esc / 外部点击可关闭
4. 弹窗内三视图和节点详情仍可用
5. 1440 下弹窗不占满全屏
6. 1024 下仍可读
7. 0 console error
