# 调度血缘与代码预览重设计

> 状态：原型提案，未改运行时代码。  
> 原型：[schedule-lineage-redesign.html](../../prototype/schedule-lineage-redesign.html)  
> 截图：[文件预览](../../prototype/shots/schedule-lineage-redesign.png) · [全宽工作台](../../prototype/shots/schedule-lineage-redesign-work.png)

## 1. 要解决的问题

当前 `task.yaml` 的文档预览和全宽血缘工作台是两套体验：

- 卡片里塞不下 DAG，只能横向滚动；
- 打开全宽工作台后丢失文件上下文；
- 设计/生产/调度三个视图存在，但调度视图和数据文件没有形成同一个对象；
- 任务、group、job、tskdep 视觉层级接近；
- 参数、占位符、源码、拓扑同时出现，没有渐进披露。

## 2. 设计方向

### 两级表面

| 层级 | 职责 |
|---|---|
| 文件预览卡 | 一眼看懂任务、cron、作业、关键路径、风险 |
| 全宽调度工作台 | 探索 DAG、选中作业、查看参数和源码 |

卡片不承担完整 DAG 编排，工作台不重复文件管理。

### 文件预览卡

- 头部：task name、任务类型、cron、状态
- 统计：任务数、作业数、依赖数、占位符数
- 主区：关键路径 + 分组作业图
- 右栏：当前选中作业的 inspector
- 底部：任务参数、源码入口、打开调度视图
- 默认不展示源码

### 全宽工作台

```text
文件面包屑 / 设计 / 生产 / 调度 tabs
左侧任务列表
中间调度 DAG
右侧作业详情
底部只读说明
```

- 从文件卡打开时直接进入调度视图
- 保留 `internal-code-repo / lts_code / channel_daily / task.yaml` 面包屑
- 点击作业只更新右侧 inspector，不重排图
- 源码统一放在右侧分栏编辑器，不压在图下面，不再做源码 tab 或抽屉

## 3. 节点语义

| 类型 | 视觉 |
|---|---|
| start | 虚线小节点 |
| url | 蓝色描边 |
| group | 绿色组框，组内并行 |
| open_gauss / libra | 数据库作业，绿色描边 |
| shell | 中性描边 |
| tskdep | 橙色虚线边，跨任务依赖 |

选中节点只做一次高亮，不做大面积阴影。

## 4. 交互

- 点击节点：更新 inspector
- 点击“打开调度视图”：切换到全宽工作台
- 源码：右侧 CodeMirror 6 分栏，只读语法高亮
- 拖动中间分隔条调整预览/源码宽度
- 分栏 / 预览 / 源码三种视图模式
- Esc：从源码视图回到分栏
- 深色/浅色切换
- 1024 / 1440 / 1600 / 1920 无横向溢出

## 4.1 编辑器选型

采用 **CodeMirror 6**，不是 Monaco：

- 模块化，按 YAML / SQL 语言包加载
- 只读预览不需要 VS Code 级语言服务
- 比 Monaco 更轻，适合侧栏和离线 bundle
- 支持行号、语法高亮、搜索、折叠、主题
- 与 DSH 主题 token 对齐，不做第二套颜色系统

第一版先只读，不提供编辑、保存、提交。

## 5. 原型范围

原型包含：

- 文件预览和全宽工作台两种模式
- 真实 `channel_daily` 6 作业数据
- 节点选择
- 左右分栏
- 源码语法高亮和行号
- 分栏 / 预览 / 源码模式
- 明暗主题
- 设计说明区

原型不包含：

- DSH React Flow 的最终接入
- 真实调度平台数据
- 写操作
- 完整 LTS schema
